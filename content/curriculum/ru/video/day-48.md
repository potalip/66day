Всё, чем ты пользовался 47 дней, — ffmpeg, Remotion, Whisper — существует потому, что кто-то выложил свою работу и
написал README. Сегодня ты становишься одним из них. А ещё открытый репозиторий шаблона — лучший кейс для
видеоинженера: заказчик по одной ссылке *видит* результат и *читает*, как ты думаешь.

## Почему в репозиторий хочется зайти

Решение принимают секунд за тридцать. За это время смотрят на:

1. **Движущуюся картинку наверху.** GIF или короткий mp4 с тем, что делает шаблон. Видеошники судят глазами.
2. **Одно предложение: что и для кого.** «Шаблон на Remotion: из JSON-списка советов делает вертикальные ролики с
   субтитрами и цветами бренда».
3. **Быстрый старт в три команды.** Клонировать, установить, отрендерить. Нужен API-ключ — напиши какой и положи
   `.env.example` без настоящих значений.
4. **Вход и выход.** Пример JSON и точный файл, который из него получится. Время рендера и примерная стоимость
   ролика, если вызываются платные API.
5. **Лицензию.** Без неё никто не имеет права законно использовать твой код. Для шаблонов чаще всего берут MIT.

Две ловушки, характерные именно для видео:

- **Ассеты не твои — перелицензировать их нельзя.** Код может быть под MIT, скачанная музыка — нет. Клади в репозиторий
  CC0-ассеты или свои примеры либо объясни, где их взять. Шрифты под Open Font License обычно можно включить вместе с
  файлом лицензии.
- **У зависимостей тоже есть лицензии.** Remotion, например, бесплатен для частных лиц и небольших команд, но
  компаниям покрупнее нужна коммерческая лицензия. Дай в README ссылку на страницу лицензии вместо обещания «бесплатно
  для всех». Условия меняются — проверь актуальные.

## Шаг за шагом

### 1. Выбери и вычисти шаблон

Возьми то, чем гордишься больше всего: шаблон серии из дня 38, брендкит, нарезчик клипов, QC-этап. Убери имена
заказчиков и всё личное.

```text
Цель: превратить <папку> в публичный репозиторий шаблона, готовый к open source.
Сделай:
1. Убери секреты, имена заказчиков, личные пути. Добавь .env.example, проверь, что .gitignore закрывает .env, out/, cache/.
2. Замени лицензированные ассеты на CC0 или свои примеры (или инструкцию, где скачать). Перечисли все ассеты
   в ASSETS.md с источником и лицензией.
3. README на русском и коротко на английском: питч в одну строку, GIF наверху, быстрый старт в 3 команды,
   пример входного JSON, что получается на выходе, время рендера на моей машине, стоимость API на ролик,
   как поменять брендовый конфиг, раздел о лицензии с лицензиями ключевых зависимостей.
4. Добавь LICENSE (MIT) с моим именем и годом.
5. Проверь чистый клон: удали node_modules / venv, пройди только по README, отрендери пример.
Готово, когда: свежий клон рендерит пример строго по README.
```

GIF из примера рендера (двухпроходная палитра даёт чистые цвета и маленький файл):

```bash
ffmpeg -i out/sample.mp4 -t 6 -vf "fps=12,scale=480:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" docs/sample.gif
```

Запушь в публичный репозиторий на GitHub, добавь темы вроде `remotion`, `ffmpeg`, `video-automation`. Вставь ссылку.

> **Если застрял:** GIF весит 30 МБ? Укороти (`-t 4`), снизь fps до 10 или ширину до 360. Или вставь mp4: GitHub
> проигрывает видео, перетащенное в README при редактировании на сайте.

### 2. Верни что-нибудь сообществу

Маленький вклад — идеальный вклад. Выбери одно:

- Исправь опечатку, битую ссылку или мутную фразу в документации Remotion, Manim или Motion Canvas (всё на GitHub,
  ищи кнопку «Edit this page»).
- Ответь на вопрос в GitHub Discussions инструмента проверенным фрагментом кода.
- Заведи понятный баг-репорт с минимальным воспроизведением того, обо что ты споткнулся.
- Ответь по делу на вопрос про ffmpeg или Remotion на «Хабр Q&A» — с командой, которую сам проверил.

```text
Хочу сделать один небольшой полезный вклад в <инструмент>. Вот страница документации, на которой я застрял: <URL>.
Предложи 3 конкретных улучшения (опечатка, недостающий пример, устаревшая команда). Для лучшего подготовь
правку по правилам CONTRIBUTING и описание PR на английском. Проверю и отправлю сам.
```

Отправляй сам и своими словами. Мейнтейнеры отлично отличают ИИ-набег от человека, который реально наступил на
грабли. Вставь ссылку на PR, issue или ответ.

### 3. Рефлексия

Открой свой репозиторий с телефона глазами незнакомца. Что он должен заметить за первые десять секунд? Это и правда
первое, что он видит? Напиши два-три предложения.

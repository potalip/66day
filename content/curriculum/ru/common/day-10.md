Рано или поздно агент в четвёртый раз скажет «Готово, исправил!», а на тебя будет смотреть всё та же ошибка. Это не
значит, что у тебя не получается, — это обычный вторник. Те, кто доводит дело до конца, отличаются от тех, кто
бросает, одним: у них есть скучный надёжный способ найти поломку и пара приёмов, чтобы вытащить агента из петли.

## Цикл отладки

1. **Воспроизведи.** Заставь баг случиться нарочно — одной командой или одним кликом. Не можешь вызвать баг — не
   сможешь и доказать, что починил.
2. **Прочитай.** Медленно и целиком прочитай сообщение об ошибке. Запиши файл, номер строки и *первую* строку ошибки:
   остальное обычно хлебные крошки.
3. **Предположи.** Сформулируй одну догадку вслух: «Кажется, `data.Valute` пустое, потому что запрос не прошёл».
   Одна догадка за раз.
4. **Исправь.** Поменяй одну вещь. Маленькие правки легко откатить.
5. **Проверь.** Повтори то же воспроизведение. Потом убедись, что не сломал ничего по соседству.

Врач не выписывает три лекарства сразу в надежде, что одно поможет. Вот и ты не надо — и агенту не давай.

Самые коварные баги ничего не роняют. Программа просто молча врёт. Для них первый шаг — заранее записать, каким
*должен* быть результат, тогда разница будет видна сразу.

## По шагам

### 1. Охота на баги (50 мин)

Сохрани этот файл как `streak.mjs` в любой папке. В нём **ровно три бага**, и ни один не роняет программу.

```js
// streak.mjs — считает итоги твоего дневника «66 дней»
const log = [
  { day: "2026-11-01", minutes: 60 },
  { day: "2026-11-02", minutes: 45 },
  { day: "2026-11-03", minutes: 0 },
  { day: "2026-11-04", minutes: 90 },
  { day: "2026-11-05", minutes: 75 },
];

function totalMinutes(entries) {
  let total = 0;
  for (let i = 1; i < entries.length; i++) {
    total += entries[i].minutes;
  }
  return total;
}

function currentStreak(entries) {
  let streak = 0;
  for (let i = entries.length - 1; i >= 0; i--) {
    if (entries[i].minutes > 0) streak++;
    else break;
  }
  return streak;
}

function bestDay(entries) {
  let best = entries[0];
  for (const entry of entries) {
    if (entry.minutes < best.minutes) best = entry;
  }
  return best.day;
}

const total = totalMinutes(log);
console.log(`Всего: ${(total / 60).toFixed(1)} ч`);
console.log(`Серия сейчас: ${currentStreak(log)} дн.`);
console.log(`Лучший день: ${bestDay(log)}`);
console.log(`В среднем: ${Math.round(total / log.lenght)} мин/день`);
```

**Сначала воспроизведи — руками.** Посмотри на дневник и посчитай на бумажке правильные ответы: сколько всего часов,
какая сейчас серия, лучший день, среднее число минут в день. Потом запусти:

```bash
node streak.mjs
```

Обведи каждую строку, где вывод расходится с бумажкой. Каждое расхождение указывает на свою функцию.

**Предположи, прежде чем спрашивать.** Десять минут погадай сам — после пятого дня ты знаешь JavaScript лучше, чем
думаешь. Потом зови агента, но заставь его идти по циклу, а не переписывать всё подряд:

```text
Цель: найти баги в streak.mjs. Файл пока не редактируй.

Контекст: для этого дневника правильный вывод такой: Всего 4.5 ч, Серия сейчас 2 дн., Лучший день 2026-11-04,
В среднем 54 мин/день. Фактический вывод: <вставь, что получилось>.

Ограничения:
- Для каждой неверной строки покажи конкретную строку кода, которая виновата, и объясни причину одним предложением.
- Предложи самое маленькое исправление (одна строка) для каждой, но ничего не меняй, пока я не скажу «ок».

Готово, когда: после исправлений каждая строка вывода совпадает с правильной, и ты показал мне diff.
```

Одобри правки, снова запусти `node streak.mjs` и сравни с бумажкой. Это и есть проверка.

**Доказательство:** три строки, по одной на баг: где он был и почему это ошибка — своими словами.

> **Сверь улов (открывай только после охоты):**
>
> 1. `totalMinutes` начинает с `i = 1` и пропускает первый день. Нужно с `0`.
> 2. В `bestDay` стоит `<`, поэтому находится *худший* день. Нужно `>`.
> 3. `log.lenght` — опечатка, получается `undefined`, и среднее превращается в `NaN`. Нужно `log.length`.
>
> `currentStreak` ни в чём не виновата. Заподозрить невиновную функцию и снять с неё подозрения — тоже хорошая отладка.

### 2. Вытащи агента из петли (30 мин)

Агент **в петле**, когда пробует исправления, которые ничего не меняют, переписывает всё больше кода или откатывает
собственную прошлую правку. Вот приёмы спасения — по порядку:

1. **Стоп.** Прерви его (в Claude Code — `Esc`, в большинстве терминалов работает `Ctrl+C`). Не давай копать глубже.
2. **Дай точную ошибку.** Скопируй настоящее сообщение и команду, которая его вызвала. «Не работает» — это не ошибка.
3. **Сузь область.** Назови один файл или функцию, которые можно трогать. Всё остальное запрети.
4. **Сначала причины, потом код.** «Перечисли три возможные причины и как проверить каждую, потом жди меня».
5. **Откат.** Если код стал только хуже — вернись к последнему рабочему коммиту и начни **новую сессию** (`/clear` в
   Claude Code или новый чат) с коротким пересказом. Чистый контекст часто чинит то, что не смогли двадцать сообщений.

```bash
git status                 # что изменилось?
git diff                   # как именно?
git restore .              # выбросить незакоммиченные правки (осторожно: они пропадут)
git log --oneline          # найти последний рабочий коммит, если надо откатиться дальше
```

Потренируйся на учебной тревоге. Открой страницу с курсами из восьмого дня и в `rates.js` замени `Valute` на
`Valuta` (или, если у тебя погода, испорть параметр в адресе: `temprature_2m`). Сам не чини. Скажи агенту только
«строка с курсом сломалась, почини» и понаблюдай пару минут. Потом проведи все пять приёмов, начиная с нормального
спасательного промпта:

```text
Стоп. Никаких правок в файлах.
Строка с курсом на странице показывает запасной текст. Точная ошибка из консоли браузера:
<вставь>
Как воспроизвести: открыть index.html, обновить страницу.
Область: только rates.js. HTML и CSS не трогай.
Сначала перечисли три возможные причины по убыванию вероятности и как проверить каждую, не меняя код. Потом жди меня.
```

Закончи через `git restore .` или нормальным исправлением и убедись, что живая строка вернулась.

**Доказательство:** вставь свой спасательный промпт.

> **Если застрял:** не понимаешь, петля это или нет, — считай. Три попытки починить одну и ту же ошибку без новой
> информации — это петля. На третьей останавливайся.

## Мини-тест

Что говорит каждое сообщение и куда смотреть первым делом?

1. `TypeError: Cannot read properties of undefined (reading 'Value') at rates.js:14:31`
2. `SyntaxError: Unexpected token '<', "<!DOCTYPE "... is not valid JSON`
3. `Error: listen EADDRINUSE: address already in use :::5173`
4. `ReferenceError: totl is not defined`

> **Ответы:**
>
> 1. Не определено то, что стоит *перед* `.Value` — например, `data.Valute.USD`, — в строке 14, символ 31. Скорее
>    всего, опечатка в пути или API вернул не то, что ты ждал. Загляни в ответ во вкладке Network.
> 2. Код ждал JSON, а получил HTML-страницу — обычно это неверный адрес, который вернул страницу 404.
> 3. Порт 5173 уже занят другой программой (часто старым dev-сервером). Останови её или возьми другой порт.
> 4. Имя, которое нигде не объявлено, — здесь опечатка вместо `total`.

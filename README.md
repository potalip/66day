# FlowLeaf 66

66 days to make building with AI a habit. A bilingual (RU/EN) learning platform with two paths: **Apps** and **Video**,
built entirely around AI coding agents. Includes a game layer, a smart resource library, and a video **Studio** backed by
our own render server.

- Product spec: [docs/SPEC.md](docs/SPEC.md)
- Who builds what: [docs/OWNERSHIP.md](docs/OWNERSHIP.md)
- Agent briefs: [docs/agents/](docs/agents/)

```bash
npm install && npm run db:migrate:local && npm run dev
```

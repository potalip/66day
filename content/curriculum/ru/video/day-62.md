До запуска три дня. На 55-й день была тихая премьера, на 65-й — громкий выход. Громкому запуску нужно то, без чего
премьера обходилась: **трейлер** — 30 секунд, после которых незнакомцу хочется увидеть всё целиком. Киностудии
делают трейлеры месяцами. У тебя есть пайплайн, транскрипты всего, что ты сделал, и агент. Этого хватит.

## Трейлер — это обещание, а не пересказ

Пересказ говорит: «Вот что там происходит». Трейлер говорит: «Вот что ты *почувствуешь* — но только если посмотришь».
Схема, которая работает почти для всего:

1. **0–3 с — крючок.** Самая неожиданная фраза или картинка из всего, что у тебя есть.
2. **3–20 с — мир.** 3–5 быстрых тактов, которые показывают размах: разные выпуски, разные результаты, моменты
   «стоп, это что, кодом сделано?».
3. **20–27 с — поворот.** Одна строка: что это и для кого.
4. **27–30 с — призыв.** Название, дата, где смотреть. («Новый выпуск каждый вторник». «Попробуй бесплатно на…»)

Если финальный проект — **инструмент**, трейлер трижды и быстро показывает «на входе → на выходе». Если **шоурил** —
сам рил и есть длинная версия, а трейлер — его лучшие 30 секунд плюс имя и контакт.

## Шаг за шагом

### 1. Пусть трейлер смонтирует пайплайн (45 мин)

Все детали ты уже собрал: автонарезку по транскрипту (46-й день), монтажные листы EDL (30-й), компоненты бренда (32-й),
экспорт в разные форматы (34-й). Осталось соединить:

```text
Цель: 30-секундный трейлер финального проекта, который собирает пайплайн: trailer.edl.json + отрендеренный mp4.
Контекст: прочитай транскрипты и JSON раскадровок всех роликов проекта в out/ и мой конфиг бренда.
Шаги:
1. Предложи 8 кандидатов (файл, таймкоды входа и выхода, звучащая фраза, почему это сильно), отсортированных
   по пригодности для трейлера: неожиданность, визуальное разнообразие, эмоция. Подожди, пока я выберу 4–5.
2. Собери trailer.edl.json: крючок (0–3 с) → 3–5 тактов (3–20 с) → карточка «что это» в одну строку (20–27 с) →
   финальная карточка с названием и «где/когда» (27–30 с). Если задана музыка — склейки в долю.
3. Отрендери версии 16:9 (1920x1080) и 9:16 (1080x1920) с субтитрами в безопасной зоне.
4. Прогони qc.py по обеим.
Готово, когда: оба mp4 лежат в out/trailer/, длительность 28–32 с, QC чистый, EDL закоммичен.
```

Посмотри трижды: обычно, без звука и на телефоне на вытянутой руке. Если крючок не цепляет *тебя самого*, замени его.
Спроси одного человека: «Что это за серия/инструмент, судя по трейлеру?» Не может ответить — карточке на 20–27 с нужны
слова попроще.

> **Если застрял:** автоматически выбранные моменты кажутся случайными? Перехвати выбор: впиши 5 таймкодов в EDL
> руками. Скучную часть (склейки, субтитры, форматы, громкость) пайплайн всё равно сделает сам, а вкус останется за
> тобой.

**Доказательство для задания 1:** приложи трейлер 16:9 в mp4.

### 2. План площадок (25 мин)

Одна **главная** площадка и две-три **вспомогательные**. Правила сообществ читай сегодня, а не в утро запуска.

| Площадка | Формат | Правила, которые надо уважать |
|---|---|---|
| VK Видео / Rutube | полный выпуск или демо | Загрузи субтитры отдельным файлом, добавь таймкоды в описание, закрепи комментарий с вопросом. |
| VK Клипы / Shorts / Reels | вертикальный трейлер и 1–2 нарезки | Загружай нативно на каждую площадку, без водяных знаков других платформ. |
| Telegram-канал и чаты | трейлер прямо в посте | В чужих чатах — только с разрешения админа или в ветке для самопиара. |
| Дзен | ролик или статья «как это сделано» | Расскажи процесс — это лучше всего удерживает. |
| Хабр | только если проект — **инструмент** | Реклама в обычных статьях запрещена: пиши статью с пользой («как я собрал видеопайплайн на коде: архитектура и цифры») или публикуй анонс в хабе «Я пиарюсь». Первая статья нового автора идёт через «Песочницу» — закладывай время. |
| YouTube | для зрителей за пределами России и англоязычной версии | В России работает с перебоями — не делай его единственной площадкой. |

По каждой площадке запиши: **дату и местное время**, **какой файл**, **какое название и подпись** (из скрипта
метаданных) и **кому ты напишешь лично**: тестовым зрителям с 54-го дня, заказчику с 41-го, авторам, с которыми общался.
**Доказательство для задания 2:** вставь план.

### 3. Чек-лист перед запуском (20 мин)

Упакуй и поставь в расписание всё заранее, чтобы в день запуска оставалось нажать «Опубликовать» и общаться с людьми.
У VK Видео и Rutube есть отложенная публикация в студии; если твой скрипт загрузки умеет её через API — используй,
если нет, ставь вручную. Для YouTube это загрузка в статусе private с полем `publishAt`:

```bash
python upload.py out/episode-03.mp4 --meta out/episode-03.json --privacy private --publish-at 2026-11-07T15:00:00Z
```

Попроси агента добавить `--publish-at`, если его ещё нет (сверься с актуальной документацией API своей площадки).
Потом отметь каждый пункт:

- [ ] У каждого ролика запуска есть финальное название, описание с таймкодами, теги, язык и категория.
- [ ] Обложки выбраны и проверены в размере телефона; субтитры загружены файлом, а не только вшиты.
- [ ] Пометка об ИИ-контенте стоит там, где её требует площадка; лицензии на музыку и шрифты сохранены.
- [ ] У серии есть плейлист; в конце каждого ролика — карточка со следующим.
- [ ] Отложенные публикации проверены в студии (часовой пояс!).
- [ ] Ссылки в описаниях работают, страница услуги с 61-го дня тоже там.

**Доказательство для задания 3:** вставь чек-лист с отметками.

После месяца работы в мастерской полно стружки: недоделанные репозитории, папка `test2-final-TOCHNO`, рендеры,
которые никто больше не посмотрит. Вчерашний босс сдан — самое время подмести. По чистому верстаку будущий
заказчик (и ты сам через месяц) сразу отличает новичка от человека, который доводит дело до конца.

## Ритуал дня: живые, архив и эпитафии

Посмотри всё, что у тебя есть на GitHub:

```bash
gh repo list --limit 100
```

Если `gh` не стоит — открой github.com → профиль → Repositories. Разложи всё на две кучи:

- **Живые** — работают, не стыдно показать. Приложения: главное приложение с 27-го дня, бот, инструмент с 13-го.
  Видео: проект объясняющего ролика с 27-го дня, шаблон на Remotion, шпаргалка по ffmpeg.
- **В архив** — мёртвые эксперименты. Архив делает репозиторий доступным только для чтения, но ничего не удаляет:
  `gh repo archive твой-логин/имя-репо` (или Settings → Archive this repository).

Маленький сюрприз: перед архивацией напиши каждому эпитафию в одну строку — в файл `GRAVEYARD.md` в главном
репозитории. «„Вежливый отказ“, день 11. Научил меня, где живут ключи. Покойся с миром». Звучит смешно, но так
«потерянное время» превращается в список уроков.

## 1. README для каждого живого проекта (20 минут)

Открой каждый такой проект с агентом и вставь:

```text
Цель: напиши README.md, который незнакомый человек поймёт за 30 секунд.
Контекст: сначала прочитай код и файлы зависимостей. Я новичок и показываю свои работы.
Что включить: одно предложение «что это и для кого», путь к скриншоту или GIF (картинку добавлю вручную), как запустить — не больше трёх команд, на чём сделано, какие планы дальше.
Ограничения: простые слова, без рекламы и стены бейджей. Код не трогай.
Готово, когда: README.md есть, и каждая команда из него реально работает — проверь, запустив.
```

В видеотреке есть ещё одна уборка: рендеры съедают диск. Проверь `du -sh */` (на Windows — правый клик по папке →
«Свойства») и удали папки с промежуточными кадрами, которые можно сгенерировать заново. Мастер-файлы и код, который
их сделал, оставь.

> **Если застрял:** «три команды» из README не работают на свежем клоне? Это настоящий баг, и README только что его
> нашёл. Почини сейчас: ничего полезнее за сегодня ты не сделаешь.

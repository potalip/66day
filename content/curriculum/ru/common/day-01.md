Через полчаса у тебя на экране будет настоящая веб-страница, которую ты описал обычными словами, — без единой
строчки кода, написанной руками. И это не учебная поделка: завтра она уедет в интернет, а на ней будет твоё
обещание самому себе на ближайшие 66 дней.

## Что такое агент для кода

Чат-бот выдаёт код, который ты копируешь. **Агент** работает *прямо в папке на твоём компьютере*: читает файлы,
создаёт новые, запускает команды, смотрит на результат и переделывает. Представь шустрого стажёра-программиста за
твоей клавиатурой. Что строить и хорошо ли получилось — решаешь ты.

Чем агент не является: телепатом и истиной в последней инстанции. На размытую просьбу он уверенно сделает не то.
Перед тем как менять файлы или запускать команды, он спрашивает разрешения — читай эти вопросы, отвечать «да»
теперь твоя работа.

**Терминал** — окно, куда вводят команды текстом. На macOS это «Терминал» (Cmd+Пробел → «Терминал»), на Windows —
Terminal или PowerShell из меню «Пуск», на Linux — Ctrl+Alt+T почти везде.

## Шаг 1. Ставим агента (15 минут)

Основной пример в программе — **Claude Code**. Ему нужна **платная подписка Claude (Pro или выше) или кредиты API**
в Anthropic Console: в бесплатном тарифе его нет. Условия меняются — перед оплатой загляни на актуальную страницу.

> **Важно:** Claude официально доступен не во всех странах — в России, например, его нет, а российской картой
> иностранные сервисы обычно не оплатить. Из Казахстана, Армении, Грузии, Сербии, Израиля или ЕС, скорее всего,
> всё заработает. Если нет — не мучайся и не нарушай правила сервиса: подойдёт любой толковый агент, доступный там,
> где ты живёшь. Codex CLI от OpenAI, Gemini CLI от Google, редактор Cursor, открытые OpenCode и Aider (они
> работают с разными моделями). Ассистенты для кода есть и у российских компаний — проверь их текущие возможности.
> Все промпты в программе написаны так, чтобы подошли любому агенту.

Установка Claude Code официальным установщиком (больше ничего не нужно):

```bash
# macOS, Linux или WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell
# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
```

Если у тебя уже стоит Node.js, можно и так: `npm install -g @anthropic-ai/claude-code`. На Windows установщик может
попросить Git for Windows — поставь его командой `winget install --id Git.Git -e` и перезапусти терминал.

Теперь создай папку проекта и запусти агента в ней (по одной строке):

```bash
cd ~
mkdir 66-day-promise
cd 66-day-promise
claude
```

При первом запуске откроется браузер для входа. Потом напиши агенту `привет! что ты умеешь делать в этой папке?`
и нажми Enter. Да, по-русски он понимает отлично.

> **Если застрял:** «command not found» сразу после установки почти всегда лечится перезапуском терминала. Закрой,
> открой заново, набери `claude --version`. Не помогло — скопируй ошибку целиком в любой чат-бот и спроси, что она
> значит. Это не жульничество, а навык.

**Доказательство:** вставь вывод `claude --version` (или версию своего агента) и его первый ответ.

## Шаг 2. Собираем страницу-обещание (15 минут)

Скопируй промпт, перепиши блок «Обо мне» про себя и отправь агенту:

```text
Цель: сделай в этой папке одностраничный сайт «Моё обещание на 66 дней».

Обо мне: меня зовут Катя. 66 дней, начиная с сегодняшнего, я по часу-два в день учусь
делать приложения и видео с помощью ИИ-агентов. К 66-му дню хочу собрать Telegram-бота,
который напоминает ученикам моей мамы-репетитора о занятиях.

Содержание: крупный заголовок с обещанием, короткий абзац «зачем мне это», что я построю
к 66-му дню, сегодняшняя дата как дата старта и сетка из 66 квадратиков (первый закрашен)
как шкала прогресса.

Ограничения: один файл index.html, стили внутри него, без фреймворков и картинок из интернета.
Спокойно и красиво: много воздуха, один акцентный цвет, аккуратная типографика на системных
шрифтах, удобно читать с телефона. Светлая и тёмная тема автоматически, по настройкам системы.

Готово, когда: index.html создан и ты открыл его в моём браузере по умолчанию.
```

Разреши агенту создать файл. Если он не открыл страницу сам, открой её:

```bash
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

Что-то не нравится — говори прямо, как дизайнеру: `заголовок крупнее, квадратики круглые`, `зелёный как в
поликлинике, давай тёплый, лиственный`. Два-три круга правок — нормально.

> **Совет:** агент не видит твой экран. Описывай, *что* не так и *где*: «в узком окне сетка вылезает вправо».

**Доказательство:** скриншот страницы в браузере.

## Шаг 3. Запиши (10 минут)

Три-пять честных предложений: зачем ты здесь и что конкретно хочешь построить к 66-му дню? «Бот, который
собирает заявки на мой маникюр» лучше, чем «что-нибудь с ИИ». На 66-й день ты это перечитаешь.

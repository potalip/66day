Чтобы руководить агентом, писать код не обязательно, а вот *читать* — нужно. Хотя бы настолько, чтобы знать, где что
лежит, и замечать, когда что-то не так. Сегодня твоя страница-обещание перестаёт быть чёрным ящиком.

## Три слоя за десять минут

Любая веб-страница — это три вида текста, которые работают вместе. Как в квартире:

- **HTML** — стены и комнаты: что есть на странице. Заголовки, абзацы, кнопки. Записывается тегами:
  `<h1>Моё обещание</h1>`.
- **CSS** — отделка: как это выглядит. Цвета, размеры, отступы, расположение. Записывается правилами:
  `h1 { font-size: 3rem; }`.
- **JavaScript** — электрика: что включается и двигается. Твой счётчик дней, кнопки, которые что-то делают.
  Записывается инструкциями: `counter.textContent = "День " + n;`.

В твоём `index.html` CSS живёт в `<style>…</style>` наверху, HTML — в `<body>`, а JS — в `<script>…</script>`
ближе к концу. Открой файл командой `cat index.html`, а лучше — в редакторе кода. VS Code бесплатен на всех системах
(`brew install --cask visual-studio-code` или `winget install Microsoft.VisualStudioCode`), но сгодится любой
текстовый редактор.

Теперь попроси агента провести экскурсию:

```text
Объясни мне index.html по частям, как новичку. Для каждой части укажи номера строк,
одним предложением — что она делает, и одну вещь, которую там можно безопасно поменять.
Ничего не редактируй.
```

## Шаг 1. Играем в DevTools (20 минут)

В каждом браузере есть **DevTools** — инструменты разработчика: панель, которая показывает код открытой страницы
и позволяет менять его на лету. Открой свою живую ссылку на GitHub Pages в Chrome, Яндекс Браузере, Edge или Firefox
и нажми **F12** (на Mac — **Cmd+Option+I**).

1. Нажми на значок стрелки в левом верхнем углу панели, а потом на свой заголовок. Панель **Elements** перепрыгнет к
   его HTML.
2. Дважды кликни по тексту заголовка в панели и впиши что-нибудь своё. Enter — страница поменялась.
3. В блоке **Styles** справа найди цвет (маленький квадратик рядом со значением), кликни и выбери другой.
4. Выбери любой элемент, кликни по нему правой кнопкой в Elements и нажми **Delete element**. Исчез.

Теперь обнови страницу. Всё вернулось. Правки в DevTools живут только в твоём браузере и только до перезагрузки —
идеальная песочница, чтобы примерить идею, прежде чем просить кого-то её строить.

**Доказательство:** скриншот страницы с тремя твоими изменениями и открытыми DevTools.

## Шаг 2. Одна правка руками, другая — агентом (25 минут)

**Руками.** Открой `index.html` в редакторе. Через Ctrl+F (Cmd+F) найди абзац «зачем мне это» и перепиши одно
предложение. Или найди акцентный цвет (выглядит примерно как `#2f7d4f`) и поставь тот, что подобрал в DevTools.
Сохрани, обнови локальную страницу, проверь.

> **Если застрял:** после правки страница сломалась? Скорее всего, ты случайно стёр `<`, `>` или закрывающий тег
> вроде `</p>`. Отмени через Ctrl+Z (Cmd+Z) в редакторе и попробуй ещё раз или спроси агента: «я правил 42-ю строку,
> и страница сломалась — что я сделал?».

**Агентом:**

```text
Цель: добавь внизу маленький подвал с текстом «День 5: я прочитал свой код.» приглушённым цветом.

Ограничения: только подвал, остальное не трогай. После правки скажи, какие именно строки
ты добавил, чтобы я нашёл их в редакторе.

Готово, когда: моя ручная правка и твой подвал закоммичены вместе с сообщением
"day 5: hand edit + footer" и запушены. Выведи ссылку на коммит на GitHub.
```

Найди строки агента в редакторе. Прочитать, что он сделал, — в этом весь смысл.

**Доказательство:** ссылка на коммит.

## Мини-тест

```html
<style>
  :root { --accent: #2f7d4f; }
  .grid { display: grid; grid-template-columns: repeat(11, 1fr); gap: 6px; }
  .cell.done { background: var(--accent); }
</style>
<h1 id="promise">66 дней. По часу в день.</h1>
<div class="grid" id="grid"></div>
<script>
  const start = new Date("2026-11-04");
  const n = Math.floor((Date.now() - start) / 86400000) + 1;
  document.getElementById("promise").textContent += " День " + n;
</script>
```

1. Какую строку поменять, чтобы зелёный сменился везде?
2. Какая строка решает, сколько квадратиков в одном ряду?
3. Какая строка вычисляет, какой сегодня день?
4. Текст заголовка — это HTML, CSS или JS? А слова « День 7» после него?

<details><summary>Ответы</summary>

1. `:root { --accent: #2f7d4f; }` — CSS-переменная: всё, что использует `var(--accent)`, перекрасится вслед за ней.
2. `grid-template-columns: repeat(11, 1fr)` — 11 колонок, значит, 66 квадратиков встанут в 6 рядов.
3. `const n = Math.floor(...) + 1;` — миллисекунды с даты старта, делённые на число миллисекунд в сутках.
4. Заголовок — HTML, а « День 7» дописывает JavaScript при загрузке страницы.

</details>

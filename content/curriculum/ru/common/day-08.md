Твоя страница уже в интернете, но она застыла: в три ночи и в полдень на ней одно и то же. Сегодня она заговорит с
внешним миром. Почти всё, что ждёт тебя дальше (ИИ-инструменты, боты, видеоконвейеры), сводится к одному: твой код
вежливо просит другую программу о чём-то. Такой разговор называется вызовом API, и после сегодняшнего дня никакой
магии в нём не останется.

## Запрос, ответ, JSON

**API** (программный интерфейс) — это дверь, которую одна программа оставила открытой для других. В вебе в неё стучатся
**HTTP-запросом**. У него есть:

- **метод** — `GET` («дай мне») или `POST` («вот данные, поработай с ними»);
- **адрес (URL)** — часто с параметрами после `?`, разделёнными `&`: `?latitude=55.75&longitude=37.62`;
- **заголовки** — служебные пометки вроде «я понимаю JSON» или «вот мой ключ»;
- иногда **тело** — данные, которые ты отправляешь вместе с `POST`.

Сервер присылает **ответ**: **код статуса** (`200` всё хорошо, `404` не найдено, `401` нет доступа, `429` слишком
часто, `500` сервер сломался), заголовки и тело. Тело сейчас почти всегда в формате **JSON** — это обычный текст,
похожий на вложенные списки с подписями:

```json
{ "Valute": { "USD": { "Name": "Доллар США", "Value": 81.25 } } }
```

Представь столовую: меню — это документация API, твой заказ — запрос, поднос — ответ, а JSON — правило, по которому
всё разложено на подносе, чтобы вилка всегда лежала справа. Чтобы достать курс доллара в JavaScript, идёшь по
подписям: `data.Valute.USD.Value`.

Сегодня у нас два бесплатных API без регистрации и ключей: **курсы ЦБ РФ** в JSON от cbr-xml-daily.ru и погода
**Open-Meteo**. Если живёшь не в России и рубль тебе не интересен — бери погоду, шаги те же.

## По шагам

### 1. Постучись через curl (30 мин)

`curl` — утилита, которая отправляет запрос из терминала и печатает ответ. На Windows сегодня во всех командах пиши
`curl.exe` вместо `curl`: в старом Windows PowerShell просто `curl` — это совсем другая команда под тем же именем.
Курсы на сегодня:

```bash
curl -s https://www.cbr-xml-daily.ru/daily_json.js | python3 -m json.tool
```

`python3 -m json.tool` — это тот самый Python, установленный на третий день: он превращает длинную строку в
читаемую лесенку. На Windows пиши `python`. Хочешь увидеть код статуса и заголовки — убери трубу `|` и добавь `-i`,
а потом найди в выводе `HTTP/2 200` и `content-type`.

Вариант с погодой: сначала узнай координаты города, потом спроси текущую погоду.

```bash
curl "https://geocoding-api.open-meteo.com/v1/search?name=Almaty&count=1&language=ru"
curl -s "https://api.open-meteo.com/v1/forecast?latitude=43.25&longitude=76.92&current=temperature_2m,wind_speed_10m&timezone=auto" | python3 -m json.tool
```

> **Если застрял:** кавычки вокруг адреса обязательны. Без них оболочка считает `&` командой «запусти в фоне» и
> обрезает URL. Видишь `command not found: python3` — попробуй `python`.

**Доказательство:** вставь отформатированный JSON — целиком или кусок со своей валютой или городом.

### 2. Живые данные на странице (50 мин)

Открой репозиторий страницы-обещания в агенте и дай ему такой промпт:

```text
Цель: показать на моей странице «66 дней» живые данные — курс валют ЦБ РФ.

Контекст: это статический сайт на GitHub Pages (чистые HTML/CSS/JS, без сборки).
API без ключа: https://www.cbr-xml-daily.ru/daily_json.js
Мне нужны валюты: USD, EUR и <ещё одна, например KZT, AMD или CNY>.

Ограничения:
- fetch() в отдельном маленьком файле rates.js, без библиотек.
- Учитывай поле Nominal: некоторые курсы даны за 10 или 100 единиц. Показывай цену одной единицы.
- Одна дружелюбная строка, например: «Сегодня по ЦБ: $1 = 81,25 ₽, €1 = 94,10 ₽». Дату курса бери из поля Date.
- Пока грузится — «Узнаю курс…». Если запрос упал — спокойная запасная строка, а не сломанная страница.
- Стиль как у остальной страницы, нормально выглядит на телефоне.
- В конце объясни простыми словами в 5 пунктах, что делает код.

Готово, когда: я открываю index.html локально и вижу живую строку; потом закоммить с понятным сообщением и запушь.
```

Для погоды замени адрес API и попроси строку вроде «В Алматы сейчас +4°, ветер 11 км/ч — погода для кода».

Прочитай пять пунктов агента. Найди строку, где код идёт по JSON (что-то вроде `data.Valute.USD.Value`), — это тот
же путь, что и в терминале. Открой страницу локально, затем DevTools → вкладка **Network** (Сеть), обнови страницу
и кликни по запросу `daily_json.js`: там тот самый JSON. Разговор тот же, просто собеседник другой.

Проверь и плохой сценарий: в DevTools переключи сеть в **Offline** и обнови страницу. Должна появиться запасная строка.

> **Важно:** ЦБ публикует курс по рабочим дням, в выходные дата не меняется — это не баг твоего кода.

Запушь, подожди минуту, пока GitHub Pages пересоберёт сайт, и открой живую ссылку с телефона.

**Доказательство:** ссылка на живую страницу.

> **Если застрял:** консоль браузера ругается на **CORS**? Значит, сервер запретил обращаться к себе со страниц в
> браузере. Оба наших API это разрешают, так что сначала проверь адрес на опечатки, а потом вставь агенту точный текст
> ошибки.

## Мини-тест

Вот кусок ответа (числа условные):

```json
{
  "Date": "2026-11-04T11:30:00+03:00",
  "Valute": {
    "USD": { "CharCode": "USD", "Nominal": 1, "Name": "Доллар США", "Value": 81.25, "Previous": 81.6 },
    "KZT": { "CharCode": "KZT", "Nominal": 100, "Name": "Казахстанских тенге", "Value": 15.62, "Previous": 15.58 }
  }
}
```

1. Сколько рублей стоит один тенге?
2. Напиши путь в JavaScript к вчерашнему курсу доллара, если весь ответ лежит в `data`.
3. Страница внезапно показывает запасную строку, а во вкладке Network код `429`. Что случилось и что делать?
4. Доллар подорожал или подешевел по сравнению с прошлым курсом?

> **Ответы:**
>
> 1. 15,62 ₽ за 100 тенге, значит 0,1562 ₽ за один. Вот зачем нужен `Nominal`.
> 2. `data.Valute.USD.Previous`
> 3. Слишком много запросов: ты (или цикл в коде) дёргаешь API слишком часто. Подожди и убедись, что запрос идёт один
>    раз при загрузке страницы, а не в цикле.
> 4. Подешевел: `Value` 81,25 меньше, чем `Previous` 81,6.

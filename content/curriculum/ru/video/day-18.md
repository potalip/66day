Три дня ты писал `for frame in range(150)` и рисовал каждый пиксель сам. Лучший способ понять видео — и медленный
способ делать его много. **Remotion** позволяет описать кадр как React-компонент: вёрстка на CSS, шрифты с Google
Fonts, картинки, хоть графики. Потом он открывает невидимый браузер, делает снимок каждого кадра и отдаёт их ffmpeg.
Ровно то, что ты делал руками, только в промышленном масштабе.

## Четыре идеи, без которых никуда

- **Композиция** — описание видео: id, компонент, `width`, `height`, `fps`, `durationInFrames`. Живёт в
  `src/Root.tsx`. В одном проекте композиций может быть сколько угодно.
- **`useCurrentFrame()`** — внутри компонента возвращает номер кадра, который сейчас рисуется. Вся анимация —
  функция от этого числа, как и в твоих Python-скриптах.
- **`interpolate(frame, [0, 30], [0, 1], { extrapolateRight: "clamp" })`** — позавчерашний рецепт «прогресс →
  значение» одной строкой. Добавь `easing: Easing.out(Easing.cubic)` — и весь 16-й день уместился в одну строку.
- **`spring({ frame, fps, config: { damping: 200 } })`** — «физическое» движение от 0 к 1, которое естественно
  успокаивается. Меньше damping — больше пружинистости. Идеально для логотипов и появлений.

И ещё `<Sequence from={60}>`: всё внутри начинается с 60-го кадра, а `useCurrentFrame()` *внутри* снова считает с нуля.
Так таймлайн собирается из маленьких переиспользуемых кусков.

> **Важно:** Remotion бесплатен для частных лиц и маленьких компаний, а более крупным нужна платная лицензия.
> Прочитай remotion.dev/license, прежде чем брать его в работу для заказчика: правила короткие и понятные.

## Шаг 1. Проект и стартовый рендер

В мастерской (`~/66/video`):

```bash
npx create-video@latest remotion
```

Выбери шаблон **Hello World** (TypeScript) и дождись установки. Потом:

```bash
cd remotion
npm run dev
```

В браузере откроется **Remotion Studio**: таймлайн, ползунок кадров, список композиций слева. Потаскай ползунок —
каждое положение React рисует вживую. А теперь отрендери по-настоящему и засеки время:

```bash
time npx remotion render HelloWorld out/hello.mp4
```

В PowerShell на Windows: `Measure-Command { npx remotion render HelloWorld out/hello.mp4 }`. Первый рендер скачивает
браузер и идёт дольше; запусти дважды и запиши время второго. В ответ вставь команду и оба времени. Проверь файл:

```bash
ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,width,height,r_frame_rate,nb_frames -of default=noprint_wrappers=1 out/hello.mp4
```

> **Если застрял:** «Could not find composition» значит, что id в команде не совпадает с `id` в `src/Root.tsx` —
> выведи список через `npx remotion compositions`. Studio не запускается — проверь, что `node -v` не ниже 18, и отдай
> агенту полный текст ошибки. Если npm качает пакеты очень медленно или с ошибками сети, попробуй другое подключение:
> у некоторых провайдеров реестр npm работает нестабильно.

## Шаг 2. Твоя фирменная заставка

Определи бренд за две минуты: название (имя твоего дневника сборки, например «Кодокадр»), два цвета (фон и акцент),
один шрифт с Google Fonts с кириллицей. Запиши — на 32-й день это станет конфигом бренда. Задание агенту:

```text
Цель: 10-секундная фирменная заставка — новая композиция Remotion.
Контекст: проект Remotion в remotion/ (шаблон Hello World). Мой бренд: название «<твоё название>», фон <#hex>,
акцент <#hex>, шрифт <название с Google Fonts, с кириллицей>, слоган «<короткая строка>».
Ограничения:
- Новая композиция с id "Intro": 1920x1080, 30 fps, 300 кадров. Компонент в src/Intro.tsx, регистрация в Root.tsx.
- Шрифт подключи через @remotion/google-fonts (установи пакет), с кириллическим подмножеством. Без внешних картинок.
- Таймлайн на <Sequence>: 0–40 рисуется акцентная фигура (spring, damping 200); 20–70 название появляется по буквам
  через interpolate + Easing.out(Easing.cubic); 70–110 слоган проявляется и поднимается; пауза до 260;
  260–300 всё слегка уменьшается и растворяется в цвет фона.
- Все тайминги вынеси в одну константу в начале файла, чтобы я мог их крутить.
- Текст не ближе 10 % к любому краю кадра.
Готово, когда: `npx remotion render Intro out/intro.mp4` даёт 10-секундное видео без ошибок в консоли.
```

Прокрути заставку в Studio до рендера. Что-то режет глаз — поменяй одно число, посмотри снова. Когда нравится:

```bash
npx remotion render Intro out/intro.mp4
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1 out/intro.mp4
```

Длительность должна быть `10.000000` (плюс-минус несколько миллисекунд). Загрузи `intro.mp4` и закоммить проект (агент уже добавил `.gitignore`,
который пропускает `node_modules` и `out/`).

> **Совет:** попроси агента: «объясни Intro.tsx построчно, как человеку, который знает Python, но не React».
> Десять минут чтения сейчас сэкономят час завтра.

## Мини-тест

1. Нужна композиция на 10 секунд при 30 fps. Чему равен `durationInFrames`?
2. `interpolate(frame, [0, 20], [0, 100])` — что вернёт на кадре 5?
3. Компонент лежит внутри `<Sequence from={90}>`. Глобальный кадр — 120. Что вернёт `useCurrentFrame()` внутри?
4. Композиция 1080×1920, 60 fps, 450 кадров. Сколько длится и какой она формы?

<details><summary>Ответы</summary>

1. 300.
2. 25: четверть пути по кадрам — четверть пути по значениям.
3. 30: внутри Sequence кадры считаются от её начала.
4. 7,5 секунды, вертикаль 9:16.

</details>

Поставь рядом свои последние пять роликов. Скорее всего, в каждом свой оттенок зелёного, свой размер заголовков, своя
манера появляться. Зритель не сформулирует, но почувствует: «самодельное». Большие каналы лечат это не вкусом, а
**системой**: решения принимаются один раз, записываются и переиспользуются везде. Сегодня ты записываешь свою систему
кодом — и это очень пригодится завтра, когда пайплайн начнёт делать ролики без твоего присмотра.

## Конфиг и компоненты

Раздели визуальный стиль на два слоя:

- **Конфиг** (`brand.json`) — это *решения*. Цвета, шрифты, файл логотипа, отступы, скругления, пресеты анимации
  («появление — пружина, 14 кадров», «титр держится 2 секунды»), звуковая отбивка. Меняешь значение — меняются все ролики.
- **Компоненты** — это *формы*, которые читают конфиг. `Title` (титр), `LowerThird` (плашка с именем в нижней трети
  кадра), `EndCard` (финальная карточка). Внутри у них нет ни одного hex-цвета и названия шрифта — только
  `brand.colors.accent`, `brand.fonts.display`.

Нашёл `#22C55E` внутри компонента — это баг. Проверка простая: можно ли применить новый стиль, не открыв ни одного файла
компонента?

Хороший стартовый конфиг:

```json
{
  "name": "Полка знаний",
  "colors": { "bg": "#14110F", "fg": "#F5EFE6", "accent": "#E8A33D", "muted": "#9A8F84" },
  "fonts": {
    "display": { "family": "Unbounded", "weight": 700 },
    "body": { "family": "Manrope", "weight": 400 }
  },
  "logo": "brand/logo.svg",
  "layout": { "safe_margin": 0.06, "radius": 14, "type_scale": [28, 40, 60, 88] },
  "motion": {
    "enter": { "kind": "spring", "damping": 200, "frames": 14 },
    "exit": { "kind": "ease", "curve": "easeInCubic", "frames": 10 },
    "title_hold_s": 2.2
  },
  "audio": { "sting": "brand/sting.wav", "sting_gain_db": -10 }
}
```

> **Важно:** шрифт обязан поддерживать кириллицу. Половина красивых шрифтов с витрины её не умеет, и вместо заголовка
> ты получишь квадратики или чужой шрифт-заглушку. На Google Fonts включи фильтр по кириллице: Manrope, Inter, Golos
> Text, Unbounded, PT Sans, Onest — надёжный старт. Заодно у них открытые лицензии, их можно использовать в коммерческих
> роликах.

Проверь контраст: `fg` на `bg` должен читаться с телефона на солнце.

## Шаг за шагом

### 1. Собери набор

Начни с названия, цветов и шрифта, которые записал на 18-й день. Конфиг живёт в `pipeline/brand/brand.json` — это
единственный источник, из которого читает любой рендер, а компоненты — там, где ты рендерил эксплейнер 27-го дня.
Удобнее всего Remotion (компоненты там — буквально React-компоненты, и они могут импортировать JSON), но та же
структура работает на Python с pycairo.

```text
Цель: фирменный набор в моём видеопроекте: brand/brand.json + три переиспользуемых компонента + лист-образец.
Контекст: ~/66/video/pipeline/ и мой рендер (проект Remotion в ~/66/video/remotion | Python + pycairo).
Мой brand.json ниже.
Сделай:
- Типизированный загрузчик brand.json (zod или тип TypeScript в Remotion; dataclass в Python), который громко падает, если нет ключа.
- Title(text, subtitle?), LowerThird(name, role), EndCard(headline, cta, logo) — все цвета, шрифты, размеры,
  скругления и анимация берутся из конфига. Анимация — через пресеты motion.enter / motion.exit.
- Шрифты подключи правильно (Remotion: @remotion/google-fonts с кириллическим подмножеством или локальные файлы
  через staticFile; Python: локальные .ttf).
- Соблюдай layout.safe_margin для каждого элемента.
- Композиция SampleSheet: все три компонента в середине анимации на одном кадре 1920x1080, с подписями.
Ограничения: ни одного hex-цвета или названия шрифта вне brand.json. Добавь скрипт-проверку на grep, который падает, если они нашлись.
Готово, когда: одна команда рендерит out/sample-sheet.png, а проверка проходит.
```

В Remotion кадр-образец рендерится так:

```bash
npx remotion still SampleSheet out/sample-sheet.png --frame=20
```

Посмотри на лист в 100% и в размере телефона. Плашка читается? Титру есть чем дышать? Чини значениями в конфиге, а не
кодом компонентов. Загрузи лист-образец.

> **Если застрял:** если вместо твоего шрифта стоит стандартный, шрифт не успел загрузиться до снимка кадра. В Remotion
> попроси агента использовать `loadFont()` из пакета шрифтов (он дожидается загрузки) вместо CSS `@import`. Если пропала
> только кириллица — не подключено подмножество `cyrillic`. В Python просто укажи путь к `.ttf`.

### 2. Перекрась старый ролик

Возьми эксплейнер с 27-го дня или вчерашний монтаж. Сначала пусть агент заменит в нём захардкоженные титры и цвета на
новые компоненты (разовый рефакторинг) и закоммить это. Потом создай второй конфиг `brand/brand-alt.json`: другая палитра, другая пара
шрифтов, более резкий пресет `enter`. Отрендери тот же ролик с ним:

```text
Добавь в команду рендера флаг --brand (или переменную BRAND), чтобы любую композицию можно было отрендерить с
brand/brand.json или brand/brand-alt.json. Затем отрендери мой эксплейнер с brand-alt.json в out/explainer-alt.mp4.
Компоненты не трогай.
```

Перед рендером запусти `git status`: рефакторинг уже в коммите, значит, новым должен быть только JSON. Загрузи `explainer-alt.mp4`.

> **Совет:** второй конфиг — это заодно твой первый продукт. «Вот ваш ролик в ваших фирменных цветах» — услуга, за
> которую небольшие бизнесы охотно платят. Вернёмся к этому на 39-й день.

## Мини-тест

Конфиг или компонент?

1. Точный оттенок оранжевой кнопки «Подписаться».
2. Как устроена плашка: имя сверху, должность снизу, логотип слева.
3. Сколько секунд титр висит на экране.
4. Пружина, с которой появляется любой элемент.

<details><summary>Ответы</summary>

1. Конфиг (`colors.accent`).
2. Компонент — раскладка и есть форма; размеры и цвета она берёт из конфига.
3. Конфиг (`motion.title_hold_s`).
4. Конфиг (`motion.enter`), компонент только применяет пресет.

</details>
